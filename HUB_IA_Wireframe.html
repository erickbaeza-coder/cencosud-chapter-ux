Glosario IA para Product Design

Conceptos clave de IA explicados para el Chapter UX.

Prompt Fundamento

La instrucción o solicitud que le entregas a Claude. Puede incluir contexto, objetivo, restricciones, fuentes y formato esperado.

Ejemplo: "Revisa esta pantalla sin modificarla. Evalúa jerarquía, accesibilidad y casos borde."

Skill Creación

Paquete de instrucciones reutilizables que especializa a Claude en una tarea. Incluye un archivo SKILL.md y puede contener referencias o scripts.

Ejemplo: Una skill que audita pantallas con el mismo checklist de UX y Design System.

Plugin Integración

Paquete reutilizable que amplía lo que Claude puede hacer. Reúne skills, agentes, comandos, hooks y conexiones MCP en una sola instalación.

Ejemplo: El plugin Discovery Agéntico incluye 6 skills del proceso S1-S6.

MCP Integración

Model Context Protocol: estándar abierto que conecta Claude con herramientas, bases de datos y servicios externos.

Ejemplo: Un servidor MCP de Figma expone herramientas para leer el archivo de diseño desde Claude.

Quality Gate Prisma

Evaluación de calidad de diseño que mide 6 dimensiones con scoring de 100 puntos antes de entregar pantallas.

Ejemplo: Pasar el quality gate antes de hacer handoff para asegurar estándares Prisma.

Procesos agénticos

Flujos de trabajo estandarizados que combinan skills, plugins y agentes para resolver problemas de diseño end-to-end.

Discovery Agéntico (S1 → S6)

Proceso completo de discovery de producto: desde la estrategia hasta el Product Design Requirements.

S1 Estrategia → S2 Mercado → S3 Usuarios → S4 Journey → S5 Negocio → S6 PDR
Plugin: discovery-agentico Owner: Equipo WL Transversal

Diseño Agéntico (DS1 → DS3)

Del PDR a las pantallas: wireframes, generación de diseño y design directions con 3 opciones.

DS1 Wireframe → DS2 Generador → DS3 Directions
Plugin: discovery-agentico Requiere: PDR completado (S6)

Prisma Designer (DS3 → Figma)

Convierte el output DS3 en pantallas reales en Figma usando el sistema de diseño Prisma.

DS3 JSON → Validar → Crear pantallas → Quality Gate
Plugin: prisma-designer Requiere: Figma MCP + Prisma MCP

Prisma & IA

Cómo el sistema de diseño unificado PRISMA trabaja con las herramientas de inteligencia artificial del Chapter.

◆

Qué es Prisma

Sistema de diseño unificado de experiencia para las 14 banderas de Cencosud en el continente americano. Tokens, componentes, patrones y guidelines en un solo lugar.

⚙

Prisma + Claude

Claude accede al catálogo de componentes Prisma via MCP, resuelve componentes por descripción natural y valida diseños contra las design rules.

⇄

Prisma MCP

Servidor MCP que expone el catálogo de componentes, permite sync desde Figma, validación de DS3 JSON y creación de pantallas directamente.

✓

Quality Gate

Evaluación de 6 dimensiones con scoring de 100 puntos. Verifica consistencia, accesibilidad, tokens, responsive y adherencia al DS.

★

Prisma Designer Plugin

Plugin completo: sync librería, resolver componentes, validar DS3, crear pantallas en Figma y quality gate. Todo desde Cowork o Claude Code.

✎

Flujo DS3 → Figma

Desde el JSON de design directions hasta pantallas reales en Figma: validar → crear → revisar calidad. Reducción de 80% en tiempo de construcción.

Flujo Prisma con IA

Sync Prisma → DS3 JSON → Validar JSON → Resolver componentes → Crear en Figma → Quality Gate
Requiere: prisma-mcp + figma MCP Plugin: prisma-designer
